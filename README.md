# LigaPro Maven

Proyecto desarrollado en Java utilizando Maven para representar los partidos de la LigaPro mediante un grafo.

## Funcionalidades

- Registro de equipos.
- Conexión entre equipos que han jugado.
- Visualización del grafo.
- Recorrido BFS.
- Recorrido DFS.

## Equipos

- LDU
- BSC
- DQuito
- Emelec
